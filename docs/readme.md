# KOTK C Server Documentation
H1Z1:KOTK uses SOE networking protocol. There has been some documentation created already on the reversed packets. That documentation has been cloned into this repository, 
see [SOE Protocol](./soeprotocol/) for more details.

## How to Get Packets
Packets can be obtained by listening to network traffic using WireShark

## How to Read Packets
Packets can be decipherd using ImHex
